# Changelog

Notable changes to agent-ready. Versions follow [semver](https://semver.org/); a change that can
move an existing repository's grade is at least a minor release.

## 0.1.0

- First release, extracted from the grader behind [masonemery.com/ready](https://masonemery.com/ready).
- 18 deterministic checks across six categories, worth 100 points.
- `agent-ready` CLI for local checkouts and GitHub repositories, with `--json`, `--prompt`, `--claude-md` and `--min-grade`.
- Template fixes and starter `CLAUDE.md` and CI files filled in with commands read from the repository.
